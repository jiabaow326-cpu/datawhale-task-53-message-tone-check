# 参考答案与陷阱核验

## 素材逐项核对

| 项目 | 证据 | 结论 |
|---|---|---|
| 旧版本 | v1 写周二 12:00、整份材料，并标注已替代 | 不沿用旧截止或旧范围 |
| 当前版本 | v2 标注当前：两项内容周三 17:00 截止；评审为周四上午 | 重写时只引用这两项和当前截止 |
| 最近进度 | v2 记有林澈周二 15:40 的“标题今晚、替代文字明早” | 可用作当前计划，但仍可询问是否有变化 |
| 重复件 | v2 重复件与当前版逐字一致 | 不视作新的独立确认 |
| 便签 | 无记录人、创建时间、确认状态，含“今天就要”等与当前信息不一致表述 | 标记为未确认，必要时询问，不据此施压 |
| 原句含糊点 | “材料”范围不明，“今天尽快”无明确时间 | 改为列出具体两项，询问预计时间并给出截止依据 |
| 错误 AI 草稿 | 添加拖延、团队受阻、半小时期限、扩大范围、升级负责人 | 全部没有材料支持，不能直接使用 |

## 语气分析的边界

字面文本可以指出“今天尽快”没有具体时点；可以提出部分读者可能把它理解为要求立即处理。但这些只是可讨论的可能解读，不是对林澈真实心理的判断。没有语气偏好材料时，简洁/中性/友好版本都只能作为候选，不能保证消除误解。
