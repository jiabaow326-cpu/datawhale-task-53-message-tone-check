# U53 消息语气误解检查：把“催一下”改成清楚、好回应的消息

本练习面向普通用户，用完全虚构的协作场景，学习区分文字的字面内容、可能被理解的语气和真实意图。目标不是判断谁“想太多”，而是让请求更具体，并保留对方说明情况的空间。

## 文件地图

- `materials/`：待润色短消息、当前任务卡、已替代旧卡、重复件、未确认便签和错误 AI 草稿。
- `tutorial/消息语气误解检查实操教程.md`：五步教程，逐步从字面拆解到可能解读、清晰改写和人工检查。
- `reference/参考答案与陷阱核验.md`：素材版本、时间冲突、未确认信息、语气风险和参考改写。
- `templates/消息语气检查提示词模板.md`：可替换成其他场景的复用模板。
- `results/参考改写与语气检查.md`：三种语气版本和逐项核验。

## 示例背景

虚构协作者“周宁”想向“林澈”询问共享图表标题与替代文字的更新安排，以准备周四上午的评审。草稿写着“材料还没改。今天尽快给我。”当前任务卡的截止时间是周三 17:00，林澈最近说标题今晚处理、替代文字明早补。草稿作者希望尽快对齐计划，但材料没有提供收件人的语气偏好或当前时区，不要把可能解读说成确定反应。

所有姓名、组织、数字和事件均为虚构。AI 只负责提出语言上的可能解读和改写选项，不代替用户发送，也不能知道收件人的真实想法。
